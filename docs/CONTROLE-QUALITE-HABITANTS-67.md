## Livraison et périmètre

Les 64 habitants d’époque, les deux porteurs de panier et le fermier sont inclus. Les 40 personnages de la Maison des Plaisirs sont exclus. Les fichiers de `public/` et les réduits existants sont conservés ; aucune intégration dans le jeu n’a été effectuée. Le contrôle de préparation est terminé ; les propositions nouvelles et les retouches finales restent soumises à l’appréciation artistique de Raphaël. Les dix approbations antérieures sont conservées comme historique, sans les étendre aux retouches ultérieures.

Chaque dossier comprend quatre sources Aseprite individuelles, une source regroupée de 32 poses avec quatre séquences nommées, les quatre bandes PNG transparentes, quatre GIF agrandis sans interpolation, un aperçu simultané des quatre directions, une planche des 32 poses, un gros plan des visages, un comparatif initial/reprise PNG et GIF, sa chronologie et un rapport final individuel. L’index pointe vers ces versions finales. Les variantes nommées d’essais précédents conservées dans le dossier ne sont pas les fichiers de livraison ; se fier à l’index et au [manifeste avec empreintes SHA-256](../art/habitants/livraison-manifeste.json).

Les sources gardent les cadres natifs de 32, 52, 56, 60 ou 64 pixels selon l’habitant. Chaque marche comprend huit poses de 120 ms, soit 960 ms. Le fermier conserve ses véritables orientations sud/est/nord/ouest ; les 66 autres utilisent SE/SO/NE/NO. Les sources regroupées contiennent six pièces visibles séparées et les références originales masquées.

## Corrections issues du contrôle final

Les cinq regards de `villager`, `villager2`, `villagerwoman`, `villagerwoman3` et `villagerchild` ont reçu des retouches minimales pour respecter strictement les deux pixels par œil. Le pixel bleu près de la joue de l’enfant est remplacé par la couleur peau. Les attaches des bras de dos du premier villageois sont complétées. Les versions précédentes des onze premiers dossiers sont sauvegardées dans [valides-avant-controle](../art/habitants/valides-avant-controle/).

Le visage demandé explicitement pour `villagerwoman2` reste conservé, avec ses accents verticaux noir/blanc. Les regards fins du moine et les yeux immédiatement sous le casque du garde et du légionnaire sont conservés. Les yeux horizontaux à accent clair des deux premiers Romains restent composés de deux pixels.

Dans les nouveaux dossiers, le contrôle visuel a notamment amené à mieux dessiner le poisson du pêcheur, ajuster la main de la porteuse d’eau, allonger la tunique de l’enfant romain, dégager l’écharpe de l’enfant industriel, arrondir un casque de Jade, rattacher les écouteurs de la troisième femme de Jade et relever le bord du chapeau de la troisième femme astrale. Ces corrections figurent dans les modèles individuels et les exports finaux.

Le contrôle pixel par pixel a aussi repéré une fusion de teintes proches lors de l’export GIF automatique. Tous les GIF de livraison ont été régénérés dans Aseprite avec une palette indexée explicite : une entrée par couleur exacte, sans approximation. Les sources Aseprite et PNG restent en RVBA. Le [générateur d’export exact](../art/habitants/propositions/habitants-gif-exact.lua) utilise les API natives [Image](https://aseprite.org/api/image) et [Palette](https://aseprite.org/api/palette).
